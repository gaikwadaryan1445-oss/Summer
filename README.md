# Summer - Personal AI Assistant

Summer is a voice-controlled, general-purpose AI assistant built with Python.

## Features
- Voice input (Whisper)
- Voice output (Edge-TTS)
- Intelligent responses (Groq Llama 3)
- Short-term and long-term memory (ChromaDB)
- Web search and time tools
- Business tools (Mock sales and pricing)

## Setup
This app requires an environment variable named `GROQ_API_KEY` to be set.
